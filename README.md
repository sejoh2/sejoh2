# Hey, I'm Joseph 👋

**Full-Stack & Mobile Engineer · Nairobi, Kenya · Building at [Wakandi](https://github.com/Wakandi-Group-AS)**

I build products end to end: Flutter apps on the phone, React and Next.js on the web, and Node.js APIs on PostgreSQL behind them. Most of what I ship is for East African users — rental platforms, ride-hailing, agriculture, and fintech tooling for SACCOs.

Day to day I work on internal tools and customer-facing platforms at Wakandi, mostly in TypeScript and Next.js. On the side I build mobile-first products with real-time features, SMS and maps integrations, and more recently AI agents.

## HOW I WORK

- Mobile first: most of my products start as a Flutter app with a Node.js API behind it
- Web apps with React, Next.js and TypeScript
- PostgreSQL as the default database, with Supabase and Firebase for auth, storage and push
- Real-time features with Socket.IO, and SMS through Africa's Talking
- AI features with Gemini and MCP-based agents
